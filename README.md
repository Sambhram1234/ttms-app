# Trouble Ticket Management System (TTMS)

A custom ServiceNow application built to streamline IT support ticketing and assignment workflows.

## Features Included:
- **Custom Data Schema:** Custom Ticket table and staged data import architecture.
- **Data Ingestion:** System Import Set with configured Transform Map for bulk record creation.
- **Automated Workflow:** Flow Designer logic (Assign Ticket by Category) to route incoming tickets automatically based on their category.
- **Deployment:** Packaged and exported via ServiceNow Remote Update Set.
